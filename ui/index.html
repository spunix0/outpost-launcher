Info

Outpost Launcher 0.1.2

An alternative launcher for SPT 4.1.6. It starts the game the same way as the official SPT launcher: log in, version check, file cleanup, mod bundle sync, then the game with the same arguments.

Unofficial. Not made by or affiliated with the SPT team or Battlestate Games. It only works with an SPT folder and never touches live Escape from Tarkov.
